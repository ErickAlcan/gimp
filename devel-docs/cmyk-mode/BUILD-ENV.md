# Build & test environment for the cmyk-mode work (this container)

Everything below is verified working as of the baseline commit (5a569ea, GIMP 3.3.1 dev).

## Environment

```sh
source /root/gimp-env.sh     # PATH (python3.12 shim), PKG_CONFIG_PATH, LD_LIBRARY_PATH,
                             # GI_TYPELIB_PATH, XDG_DATA_DIRS, GEGL/BABL paths, LANG
```

- babl master (0.1.x, built from github.com/GNOME/babl) and GEGL master (0.4.x) are installed in `/opt/gimp-deps`.
  Sources are in `/home/claude/deps-src/{babl,gegl}` if you need to read babl's CMYK model code
  (`babl/base/model-cmyk.c`, `babl/babl-icc.c`, `babl/babl-space.c`).
- GIMP build dir: `/root/gimp/_build` (meson, debugoptimized). Reconfigure is NOT needed for code
  changes; `ninja -C _build` handles everything, including regenerating PDB wrappers when
  `pdb/groups/*.pdb` change (check `pdb/meson.build` — wrappers are regenerated by the `pdbgen`
  target and the generated `app/pdb/*-cmds.c` / `libgimp/*_pdb.c` ARE committed in git, so
  regenerate then commit them).
- The system `python3` is 3.13 but PyGObject/g-ir-scanner are built for 3.12; always use the
  shim (`source /root/gimp-env.sh` does this). Never run `apt-get upgrade`.

## Build

```sh
source /root/gimp-env.sh
cd /root/gimp && ninja -C _build 2>&1 | tail -20        # full incremental build ~ minutes
ninja -C _build app/gimp-console-3.3                   # faster: core only
```

A clean baseline build takes ~10 min; incremental builds after touching a header in
`libgimpbase/` rebuild most of the tree (~5 min). Touching `app/core/*.h` rebuilds `app/`.

## Tests

```sh
source /root/gimp-env.sh
cd /root/gimp && meson test -C _build --no-rebuild --print-errorlogs
```

Baseline: 20/21 pass. `gimp:desktop / appdata_file` fails in this sandbox because it needs
network access (ignore it). The suites that matter here:

- `gimp:app / core`  — GLib tests in `app/tests/test-core.c` (add CMYK core tests there or in
  a new `test-cmyk.c`; register it in `app/tests/meson.build`, list `tests = [...]`).
- `gimp:app / xcf`   — `app/tests/test-xcf.c` round-trips an image through XCF and compares
  every property. Extend `gimp_write_and_read_file`/`gimp_create_mainimage` for a CMYK image.
- `gimp:app / save-and-export` and the `gimp:libgimp+python3 / *` suites — Python scripts run
  inside in-build GIMP via `libgimp/tests/libgimp-run-python-test.py`. This is the mechanism
  for end-to-end tests (create CMYK image → paint → save XCF → reload → export TIFF/PSD →
  verify pixels). See `app/tests/test-save-and-export.py` as the template and
  `app/tests/meson.build` for how a test is declared (`tests = [{'name': ...}]`; add
  needed plug-ins to `GIMP_TESTING_PLUG_INS`, e.g. `file-tiff`, `file-jpeg`, `file-psd` (tools/in-build-gimp.py maps a plain name to plug-ins/<name>/<name>)).

Run one suite: `meson test -C _build --no-rebuild --print-errorlogs core` (or `xcf`, or
`save-and-export`). Logs: `_build/meson-logs/testlog.txt`.

## Running in-build GIMP headless by hand

The in-build binary needs the environment meson sets up. Easiest is to copy the `command:`
line for `save-and-export` from `_build/meson-logs/testlog.txt`, which looks like:

```sh
GIMP_TESTING_ENVIRON_DIRS=/root/gimp/_build/data/environ/ GIMP_TESTING_ABS_TOP_BUILDDIR=/root/gimp/_build \
GIMP3_SYSCONFDIR=/root/gimp/etc GIMP_GLOBAL_BUILD_ROOT=/root/gimp/_build GIMP_PYTHON_WITH_GI=/opt/py312-shim/python \
GIMP_GLOBAL_SOURCE_ROOT=/root/gimp GIMP_SELF_IN_BUILD=/root/gimp/_build/app/gimp-console-3.3 \
GIMP_TESTING_PLUG_INS=python/python-eval/:common/file-png:file-tiff:file-jpeg:file-psd \
GI_TYPELIB_PATH=/root/gimp/_build/libgimp:/opt/gimp-deps/lib/x86_64-linux-gnu/girepository-1.0 \
GIMP3_LOCALEDIR=/root/gimp/_build/po-plug-ins \
LD_LIBRARY_PATH=/root/gimp/_build/libgimpwidgets:/root/gimp/_build/libgimpthumb:/root/gimp/_build/libgimpmodule:/root/gimp/_build/libgimpmath:/root/gimp/_build/libgimpconfig:/root/gimp/_build/libgimpcolor:/root/gimp/_build/libgimpbase:/root/gimp/_build/libgimp:/opt/gimp-deps/lib/x86_64-linux-gnu \
GIMP_TESTING_MENUS_PATH=/root/gimp/_build/menus:/root/gimp/menus GIMP_TESTING_ABS_TOP_SRCDIR=/root/gimp \
GIMP_TESTING_INTERPRETER_DIRS=/root/gimp/_build/plug-ins/python/:/root/gimp/_build/extensions/ \
/root/gimp/tools/run_test_env.sh /usr/bin/python3 /root/gimp/libgimp/tests/libgimp-run-python-test.py \
/root/gimp/tools/in-build-gimp.py /path/to/your-script.py
```

`your-script.py` must start with `#!/usr/bin/env python3` and uses the `Gimp` GI module
(`from gi.repository import Gimp`), `gimp_assert(...)` is injected. The run is wrapped in
Xvfb + dbus by `run_test_env.sh` when `UI_TEST` is set; python-eval tests do not need it.

## ICC profiles for tests

No CMYK ICC profile ships with GIMP. For tests either generate a small synthetic CMYK profile
with lcms2 (`cmsCreate...` has no CMYK creator; the usual approach is a tiny LUT-based profile
written with `cmsCreateProfilePlaceholder` + `cmsWriteTag` A2B0/B2A0 tags) or vendor a
freely redistributable one (e.g. Ghostscript's `default_cmyk.icc` — check `/usr/share/ghostscript/*/iccprofiles/default_cmyk.icc`
or `/usr/share/color/icc/ghostscript/` on this box, Artifex license: AGPL — so for the
repository prefer generating). Document the choice in TESTING.md.

Profiles available on this box for local testing (not for committing):
`/usr/share/color/icc/ghostscript/default_cmyk.icc`, `/usr/share/color/icc/ghostscript/ps_cmyk.icc`,
`/usr/share/texlive/texmf-dist/tex/generic/colorprofiles/FOGRA39L_coated.icc` (FOGRA39, ECI — free to redistribute per ECI terms; check before vendoring).

## Parallel workstreams (worktrees)

Each workstream agent works in its own git worktree `/root/wt/<ws>` on branch `ws/<ws>`, branched from
`cmyk-mode` after 01a. Build there with its own build dir:

```sh
source /root/gimp-env.sh          # also sets CC="ccache gcc" — the cache is warm, builds are fast
cd /root/wt/<ws>
meson setup _build --prefix=/opt/gimp -Dbuildtype=debugoptimized -Dvector-icons=false \
  -Djavascript=disabled -Dlua=false -Dvala=disabled -Dgi-docgen=disabled -Dheadless-tests=enabled
ninja -C _build -j1               # the box has 2 cores shared by all agents: ALWAYS -j1
meson test -C _build --no-rebuild --print-errorlogs --num-processes 1
```

The gimp-data submodule is shared; run `git submodule update --init` in the worktree if `gimp-data/`
is empty (it points at the GitHub mirror via the insteadOf config in the main repo; if the clone
fails, `cp -a /root/gimp/gimp-data .`).
