# CMYK mode — test plan (revision 2)

Environment: `BUILD-ENV.md` (`source /root/gimp-env.sh`, build dir `/root/gimp/_build`,
`meson test -C _build --no-rebuild --print-errorlogs`; baseline 20/21, `appdata_file` needs
network — ignore). Test file ownership: INTERFACES §15 (01a creates and registers every file
below as a skeleton; afterwards each file has one owner). IDs: G golden, F foundation,
C compositing, P performance, I image, X xcf, L libgimp, E file formats, H histogram/pickers/
text, Z end-to-end, N no-support. Rev-1 T-numbers are mapped at the end.

## Test ICC profiles (decision)
* Repository tests use only **generated** profiles: the builtin
  (`gimp_color_profile_new_cmyk_builtin()`) and an **input-only derivative**: open the builtin
  with lcms, `cmsWriteTag (h, sig, NULL)` for **all six** BToA0/1/2 *and* the linked tags,
  `cmsSaveProfileToMem`, reopen and assert `! cmsIsIntentSupported (…, LCMS_USED_AS_OUTPUT)`.
  Helper `gimp_test_utils_cmyk_input_only_profile()` (01a, in `gimp-app-test-utils.c`).
  A **header-variant** of the builtin (bytes 24–35 changed, everything else equal) is helper
  `gimp_test_utils_cmyk_header_variant (profile)`.
* Optional real profiles: env `GIMP_TESTING_CMYK_ICC` (colon-separated). Tests using it call
  `g_test_skip()` when unset. On this box:
  `/usr/share/color/icc/ghostscript/default_cmyk.icc`,
  `/usr/share/texlive/texmf-dist/tex/generic/colorprofiles/FOGRA39L_coated.icc`.
* Nothing binary is committed. The input-only TIFF fixture is generated by the test (E7).
* Precision knob: `GIMP_TESTING_CMYK_PRECISION=u8|u16|half|float|double` (helper
  `gimp_test_utils_cmyk_precision()`, default u16) is honoured by C1, C3, C9, I7, I9, I10.

## Tier A — no rebuild needed (every WS, before asking for a merge)
1. **Switch audit**: `grep -rnE "switch \(.*(base_type|get_base_type|image_type)" <owned files>`
   → each switch has a `GIMP_CMYK`/`GIMP_CMYK(A)_IMAGE` case or an intentional `default:`.
   Range checks: `grep -rnE "GIMP_INDEXEDA?_IMAGE\b *[<>]|> *GIMP_INDEXED\b|GIMP_INDEXED *\+" …`.
2. **4-component assumptions**: `grep -rnE "\[4\]|\* 4\b|\+= 4\b|n_components *== *4|
   pixel\[(16|32)\]|\"RGBA float\"|\"R'G'B'A float\"|\"Y'?A? float\"" <owned files>`.
   **2b. Native-pixel stack buffers (M5)**:
   `grep -rnE "\b(gdouble|gfloat|guchar|guint8|guint16|guint32|gint|double|float) +[a-z_]*(pixel|sample|col|color|total|rgba?|value|data|buf)[a-z_0-9]*\[[0-9]+\]" <owned files>`
   and `grep -rnE "gimp_pickable_(get_pixel_at|pick_color)|gimp_image_pick_color|gegl_buffer_sample|gegl_color_get_pixel" <owned files>`
   — every buffer that receives a *native* (drawable/pickable/image) format is
   `MAX_CHANNELS` doubles (I10). Known sites: PLAN §5. Record each hit in your Status section
   as fixed / OK (explicit RGB format) / OK (≥ 40 bytes).
3. **Generated files untouched by hand** (PLAN §4.2): `git diff --stat` shows them only in
   "regen" commits.
4. **babl probe** (09): `python3 -I -u app/tests/cmyk-babl-probe.py` (ctypes, read-only):
   CMYK(A) formats for all 6 types, `CaMaYaKaA double` exists / `u32` missing, CMYK space
   from the builtin, I5 identities, lcms-support discriminator (INTERFACES §2), and the
   same-bytes ⇒ same-space / header-variant ⇒ different-space facts behind I8. Never feeds an
   input-only profile to an RGB→CMYK fish (segfault).
5. **Isolated compile**: `ninja -C _build libgimpcolor/libgimpcolor-3.0.so app/gegl/libappgegl.a`.

## Tier B — `ninja -C _build && meson test -C _build --no-rebuild --print-errorlogs`
Pixel checks read buffers with explicit formats (`"CMYKA u16"` + image space unless stated)
and compare **exactly** unless a tolerance is given. "Bit-identical" = `memcmp` of the bytes.
