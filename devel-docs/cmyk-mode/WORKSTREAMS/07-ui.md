# WS07 — UI: actions, menus, dialogs, display, view renderers

**Goal**: users create and convert CMYK images, see correct titles/info/display/previews, and
cannot reach unsupported features (legacy modes, MyPaint is 08's, indexed conversion).

**Owned files** (PLAN §4.1): `app/actions/*` except `channels-*`, `app/dialogs/*`,
`app/display/*`, `app/gui/*`, `app/menus/*`, `menus/*`, `app/config/*`, `app/propgui/*`,
`app/widgets/*` except 08's list (incl. `gimpviewrenderer*.c`, `gimpwidgets-utils.c`,
`gimpimagepropview.c`, `gimptemplateeditor.c`, `gimpcolormapeditor.c`,
`gimpcolormapselection.c`, `gimpselectiondata.c`, `gimpclipboard.c`, `gimplayermodebox.c`,
`gimplayermodecombobox.c`, `gimphelp-ids.h`), `libgimpwidgets/gimpwidgetsutils.c`,
`libgimpconfig/gimpcolorconfig.c` (label/tooltip only).

**Dependencies**: starts at the 01a merge. Acceptance needs 01b (lcms display transforms) and
03 (conversion). Merges eighth.

**Steps**
1. `image-actions.c`/`image-commands.c`: `image-convert-cmyk` (GIMP_CMYK) →
   `gimp_image_convert_type_full()`; sensitivity: insensitive without CMYK support; indexed
   conversion insensitive for CMYK; "use sRGB"/hidden-profile actions insensitive for CMYK;
   colormap actions insensitive.
2. `menus/image-menu.ui.in`: Image ▸ Mode ▸ CMYK; help ID.
3. `color-profile-dialog.c`: `COLOR_PROFILE_DIALOG_CONVERT_TO_CMYK` (profile chooser filtered to
   bidirectional CMYK, intent + BPC, default from `gimp_get_default_cmyk_profile()` with the
   simulation profile as preferred, **shows which profile was chosen and why** — m15);
   CONVERT_TO_RGB/GRAY from CMYK sources with intent/BPC; CMYK→CMYK convert/assign.
4. `image-new-dialog`, `gimptemplateeditor.c`: "CMYK color" in the color-space combo, profile
   combo filtered, TRC widgets hidden; `convert-precision-dialog.c`: no TRC choice for CMYK;
   `color-profile-import-dialog.c`: CMYK wording (keep / convert to preferred CMYK).
5. Layer modes: `gimplayermodebox.c`/`gimplayermodecombobox.c` and layer attribute dialogs hide
   the legacy group for CMYK images/drawables (I9); new-layer dialog offers CMYK fill types.
6. Display: title/info "CMYK color"; profile pipeline with the CMYK projection
   (`gimpdisplayshell-*`, `gimpwidgets-utils.c` transform cache, lcms); color management off →
   babl conversion; soft-proofing on CMYK images; `gimpcursorview.c:763` `pixel[MAX_CHANNELS]`.
7. View renderers (INTERFACES §10): `gimp_view_renderer_get_color_transform()` uses sRGB when
   the viewable's profile is CMYK; check `gimpviewrendererimage.c`/`-drawable.c`.
8. Widgets: `gimpimagepropview.c` (color space, profile), `gimpselectiondata.c`/`gimpclipboard.c`
   (verify CMYK colors/buffers), preferences label/tooltip "default profile for new CMYK images".
9. Tier A on owned files; manual checklist items for your dialogs (TESTING).

**Acceptance**: manual checklist items New Image, Mode ▸ CMYK dialog, title, previews, legacy
modes absent, soft-proof; no criticals on CMYK images under Xvfb; G1–G3 and existing tests
green.

**Risks**: runtime dependence on 03; dialog code shared with soft-proof selection; transform
