# WS07 — UI: actions, menus, dialogs, display

Goal: users can create and convert CMYK images and see correct titles/info/display.

Owned files: PLAN §3 (07).

Steps
1. image-actions.c/image-commands.c: `image-convert-cmyk` (value GIMP_CMYK), sensitivity
   (insensitive without CMYK support; indexed conversion insensitive for CMYK; "use sRGB" etc.
   insensitive for CMYK); call `gimp_image_convert_type_full`.
2. menus/image-menu.ui.in: Image ▸ Mode ▸ CMYK. Help ID in gimphelp-ids.h.
3. color-profile-dialog: `COLOR_PROFILE_DIALOG_CONVERT_TO_CMYK` (CMYK profile chooser filtered
   to bidirectional CMYK, intent + BPC, default from `gimp_get_default_cmyk_profile` with the
   simulation profile as preferred); also CONVERT_TO_RGB/GRAY from CMYK sources with intent/BPC.
4. image-new-dialog/template editor: CMYK in color-space combo, profile combo filtered, TRC
   hidden for CMYK. convert-precision-dialog: hide TRC choices for CMYK.
5. color-profile-import-dialog: CMYK files' policy wording (keep / convert to preferred CMYK /
   convert to RGB is out of scope).
6. display: shell title/info ("CMYK color"), profile pipeline with CMYK projection (lcms path),
   rendering when color management is off, soft-proofing on CMYK images.
7. widgets: gimpimagepropview (color space, profile), viewrenderer previews, widgets-utils, color-
   map editor insensitive for CMYK, layers-actions new-layer type selection.
8. Preferences: label/tooltip of "CMYK profile" mention it is the default for new CMYK images.

Acceptance: manual checklist B5 items 1, 2, 9, 10; no criticals in the console on CMYK images.

Risks: depends on 03 at runtime; dialog code shared with soft-proof selection.
